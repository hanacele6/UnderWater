# CRADLE PROTOCOL（旧称：UnderWater）

深海の潜水艦で目を覚ました記憶喪失の乗員たちが、
脱出を目指すSFサスペンスADV／3D探索ホラー

## 概要

年齢も性別もばらばらの人間たちが、深海に沈む潜水艦の中で目を覚ます。
残された手がかりは、この艦が何らかの実験に使われていたという事実と、その目的だけ。

プレイヤーは潜水艦を操作して外部から素材を回収し、
艦内では仲間との対話を通じて情報を集めながら、地上への帰還を目指す。

**そして探索を進めるうち、プレイヤーだけが気づく違和感がある。**

## 特徴

**見えない恐怖**
潜水艦の外は一切見えない。頼れるのはソナーに映る影と、船体を叩く音だけ。
情報を制限することで、プレイヤーの想像力に恐怖を作らせる設計。

**誰を信じるか**
仲間の心拍を感じ取れる「心電図」システム。嘘をついているのか、
それとも別の理由なのか——限られた情報から判断を迫られる。

**探索と調合のサイクル**
海中から回収するコンテナは、引き揚げるまで中身がわからない。
未知のアイテム同士を組み合わせ、試行錯誤しながら活路を見つけ出す。
