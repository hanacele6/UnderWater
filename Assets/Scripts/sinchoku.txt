🟩 【完成済み】基本システム・基盤

ゲームの根幹となるロジックやパイプラインはすでに構築完了しています。

    [ ] 日数とゲームフェーズシステム

        日付（Day）のカウント、および朝・昼・夜・事件などのフェーズ（Phase）切り替えロジック

    [ ] 潜水艦操作システム

        3D空間での潜水艦の移動、旋回、および操縦モードへの移行・ロック処理

    [ ] ミッションシステム

        インベントリのアイテムを消費してストーリー進行用ミッションを提出する仕組み

    [ ] アイテム調合と栽培システム

        回収した素材を組み合わせて新しいアイテムを作る、および時間経過で素材が増える仕組み

    [ ] アイテムの使い道（汎用エフェクトパイプライン）

        装備やアップグレードツリー解放時に、複数のステータス補正やスキルフラグを一括適用・解除する仕組み

    [ ] 会話・イベントシステム（土台）

        GameEventData（ScriptableObject）による発生条件、フラグ、ながら会話、演出設定のデータ構造化

🟨 【要実装】これから作る明確な不足要素

ゲームフローを1つのパッケージとしてつなぎ合わせるために必要な要素です。

    [ ] Menu内の「Map」タブ実装

        潜水艦内の各部屋のマップ表示、および部屋間を瞬時に移動できるファストトラベル機能

    [ ] NPCスケジュール・状態マネージャー（立ち位置の分離）

        イベント中とは別に、普段（日常）のフェーズや日付に連動して10人のNPCがどの部屋にいるかを一括管理・移動させるシステム

    [ ] フェーズ連動型のマップ動的装飾システム

        ゲームの進行度（フェーズやイベント）に合わせて、特定のドアをロックしたり、船内のライトを非常灯（赤）に切り替えたりする仕組み

    [ ] 統合オーディオマネージャー（AudioManager）

        BGMのクロスフェード（フェーズ移行時）、環境音（WAVループ）、UIシステム音やソナー音（SFX）、音量設定の一元管理システム

    [ ] ゲームオーバー（敗北・デッド）処理

        潜水艦のHP（maxHP/currentHP）が 0 になった瞬間の暗転、セーブポイントへのリザルト、および復帰フロー

    [ ] チュートリアル・オンボーディング進行

        ゲーム開始直後に、コンソールのタブを段階的にアンロックしたり、操作説明のポップアップを表示してプレイヤーの迷子を防ぐ仕組み

    [ ] セーブ・ロードシステム

        現在の日付、フェーズ、インベントリ、アップグレード解放状態、装備、イベントフラグ等のデータを保存・復元する仕組み（JSON等）

🟦 【要手配】アセット・ビジュアル・演出の刷新

ゲームの見た目や手触りを「本番クオリティ」に引き上げるためのタスクです。

    [ ] 栽培するサンプルの3Dモデル / エフェクトの作成と差し替え

    [ ] 登場キャラクター（10人分）の2Dグラフィック・立ち絵画像の手配

    [ ] UIの全面刷新（フリーアセット等からの製品版デザインへの置き換え）

    [ ] UI操作感の統一

        全てのパネルを「Tabキーで切り替え」「Escキーで閉じる」など、操作ボタンの挙動を完全に統一する調整
